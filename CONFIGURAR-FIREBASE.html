Espaço da Picanha — Configurar Firebase

1. Acesse Firebase Console → Configurações do projeto → Seus aplicativos → Aplicativo Web → Configuração do SDK.

2. Copie o objeto firebaseConfig completo e cole abaixo. Não cole senhas nem chaves privadas.

3. Salve o arquivo baixado dentro da pasta do sistema, substituindo o firebase-config.js de exemplo.

4. Abra index.html pelo Live Server do VS Code. Se publicar no GitHub, envie também o arquivo atualizado. No Firebase Authentication, autorize o domínio do seu site.
